# 课堂素材生成器 · 给老师的一页纸

一个给学生用的网页小工具：学生说一句话 → 生成**家乡配图**或**4–12 秒短视频**（固定 720P），素材直接放进《家乡介绍》PPT。

对应初中信息科技「生成式人工智能（AIGC）应用」主题课堂（例：冀教版七年级 1.2《AIGC 帮我讲家乡》）。

> **这个包里没有密钥，也没写死任何机器路径。** 两位老师想用，各自填自己的 key 就行。

---

## 三步开始用

### 第 1 步 · 拿到两个 key

| 要什么 | 干什么用 | 去哪申请 |
|---|---|---|
| **Agnes key** | 生成图片和视频 | Agnes AI 开放平台注册后台的 API Keys 页面（文生图 / 文生视频） |
| **DeepSeek key** | 帮学生把中文原话改成英文提示词 | DeepSeek 开放平台，控制台里创建，形如 `sk-xxxx` |

两个都是 `sk-` 开头的一长串。**从后台复制出来的 Agnes key 有时会自带一串前缀（形如 `xxx: sk-......`），
要的是 `sk-` 开头那一整段，别把前面的前缀一起粘进来。**

### 第 2 步 · 把 key 填进配置

用记事本打开 **`config.json`**，把这两行引号里的内容换成你的：

```json
"agnesKey": "",
"deepseekKey": "",
```

> 只填 `sk-` 开头那一串，别带空格、别带换行、别带说明文字。
> 填完**不用重启**，下次双击 `启动.bat` 就生效。

不想碰文件的话，也可以设在系统环境变量里：`AGNES_API_KEY` 和 `DEEPSEEK_API_KEY`。

### 第 3 步 · 启动

1. 确认装了 **Node.js 18 以上**（没装先去 nodejs.org 装，一路下一步）
2. 双击 `启动.bat`
3. 等黑窗口出现下面这几行（文生图脚本**已经打包在 `agnes/` 里，你不用另外装**）：

```
==== 课堂素材生成器已启动 ====
本机打开 : http://localhost:8788
同 WiFi 学生手机/平板 : http://192.168.x.x:8788
Agnes key : 已配置（纯 ASCII）
DeepSeek : 已配置（纯 ASCII）
```

- 你自己的电脑浏览器开 **`http://localhost:8788`**
- 学生的手机 / 平板连**同一个 WiFi**，开黑窗口里打印的那个 **`http://192.168.x.x:8788`**
- **黑窗口别关**

## 学生怎么用（一句话流程）

> 说一句话 → 点「✨ AI 帮我写提示词」→ 选画风、选图片/视频 → 「开 始 生 成」→ 下载

- 出图片几秒；出**视频要等 1–3 分钟，中途别关页面**
- 下载后**把页面上那段提示词一起抄进作业**（作业要求标注「AI 生成 + 提示词」）
- 页面上会显示「本课第 N 份作品」（本机记数，方便老师清点）

## 学生端看不到密钥

key 只在你这台电脑的服务里跑，发给学生的只有一个网页界面。学生右键「查看源代码」也**找不到任何 key**。

## 合规（三层，自动执行）

1. **敏感词黑名单**（约 70 条）：色情、暴力、毒品、自残、赌博、邪教、霸凌、歧视、政治敏感……
2. **AI 提示词规则**：社会主义核心价值观、中学生（12–15 岁）素养、画面不许出现文字/水印/logo、不许用他人肖像和受版权角色
3. **AI 产出再复核一遍**，不合格直接拦下

学生只要写「家乡的一处风景 / 一道老小吃 / 一门老手艺」这种积极主题就都能过。

## 出问题看这里

| 现象 | 怎么办 |
|---|---|
| 黑窗口一闪就没 | 装 Node.js 18+ 后重开 |
| 窗口说「Node.js not found」 | 同上，或重开一次命令行让它进 PATH |
| 页面提示「key 没配好」 | `config.json` 里还是空的 / 占了位符，或 key 带了空格 |
| 提示「含非 ASCII 字符」 | key 粘成了说明文字，重新只粘 `sk-` 那段 |
| 横幅说「【没找到】Agnes CLI」 | 把文生图脚本 `agnes_media.py` 拷进本目录的 `agnes/` 文件夹 |
| 视频报「视频队列满了」 | 平台排队满，程序已自动重试 3 次；还不行让学生先做图片，等一两分钟再试 |
| 端口被占（8788 被别的软件） | 会自动换到 8789 / 8790，横幅里写清楚了，**照着横幅的地址发给学生** |
| 学生手机打不开 | 不在同一 WiFi / 黑窗口被关了 |

不开浏览器也能验收（黑窗口开着，另开一个命令行）：

```
node smoketest.js
```

末尾给 `passed / failed`。

## 文件清单

| 文件 | 说明 |
|---|---|
| `README.md` | 本文档 |
| `SKILL.md` | 技能自带说明（详细版） |
| `config.json` | **你填 key 的地方，别外传** |
| `启动.bat` | 双击启动 |
| `server.js` | 服务端（零第三方依赖） |
| `smoketest.js` | 自检脚本 |
| `agnes/agnes_media.py` | **文生图 / 文生视频脚本，已自带**（纯标准库，无需另装 agnes 技能） |
| `public/index.html` | 学生端网页 |
| `示例效果_扁平插画.png` | 样例出图 |
| `学生作品素材/` | 自动创建，生成的文件落在这（图在 `images/`，视频在 `videos/`） |

**整个包不到 1.5 MB，零第三方依赖**：只要一台装了 Node.js 18+ 的电脑，两个 key 填进 `config.json`，
双击 `启动.bat` 就能开课。可以直接压缩发给同行，或把整个文件夹拷进 `~/.workbuddy/skills/` 当技能安装。

> 解压后如果班长出「中文路径」问题，把整个文件夹放在纯英文路径下（如 `D:\tools\classroom-media-studio`）更稳。
